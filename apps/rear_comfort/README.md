# Rear Comfort

Full-screen driver control for the BMW G12 rear compartment.

Controls:

- independent rear climate temperature, blower and automatic mode
- rear-left and rear-right seat heating and ventilation
- massage intensity and programme for both rear seats
- guarded seat position, headrest, cushion and footrest adjustment
- left, right, rear and all-shade operation
- both rear entertainment screens, display brightness and remote navigation

The app uses BMW's own live services and reads the confirmed state back from the car. Seat movement is accepted only while stationary.
